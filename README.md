## 🥊 About

This project documents and preserves the original **Street Fighter IV PC environment from 2009**, with particular attention to the early Windows release and its legacy software dependencies.

The preservation set was assembled around an archival optical-media dump of the **Synergex de Argentina** release and a separately maintained known-working installation.

The objective is to preserve not only the game itself, but also the historical software environment surrounding it.

### Preserved components

- Original optical-media dump
- Known-working installation
- Games for Windows LIVE
- XLive compatibility material
- Legacy runtime dependencies
- DirectX June 2010 runtime
- Diagnostic utilities
- Save/unlock utilities
- Installation documentation
- Troubleshooting documentation
- Artwork provenance
- Original soundtrack metadata
