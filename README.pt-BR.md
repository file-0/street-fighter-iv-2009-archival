## Sobre o projeto

Este projeto documenta e preserva o ambiente original de
**Street Fighter IV para PC de 2009**, com atenção especial
à versão inicial para Windows e às suas dependências de
software da época.

A coleção foi construída a partir de uma imagem arquivística
da versão argentina distribuída pela **Synergex de Argentina**
e de uma instalação de trabalho mantida separadamente.

O objetivo não é apenas preservar o jogo, mas também o
ambiente de software necessário para reproduzir sua execução
em sistemas Windows modernos.

### Componentes preservados

- imagem original da mídia;
- cópia de trabalho funcional;
- Games for Windows LIVE;
- material relacionado ao XLive;
- dependências de runtime;
- DirectX de junho de 2010;
- ferramentas de diagnóstico;
- ferramentas de save/desbloqueio;
- documentação de instalação;
- documentação de troubleshooting;
- informações de procedência de artworks;
- metadados da trilha sonora.

## 💿 Mídia original

A principal referência arquivística é uma imagem da versão
argentina de varejo distribuída pela Synergex de Argentina.

vezes utilizando DiscImageCreator / MPF 2.3 e ambos os dumps
apresentaram correspondência.

A mídia também foi verificada utilizando:

- CDCheck 3.1.14.0
